# Bone Circuit skin sources

`librequake/` is a minimal, pinned input set from LibreQuake revision
`dd4d5bffcabbcf9ceca32a1d83829109928c3f08`:
<https://github.com/lavenderdotpet/LibreQuake/tree/dd4d5bffcabbcf9ceca32a1d83829109928c3f08>.
It contains only the 48 PNGs and nine brush-model map sources used by RAVAGE's
skins (health/large health share a map). LibreQuake's BSD-3 license and credits
are included alongside them. Geometry is not regenerated by the skin-only path.

PNGs were normalized to 8-bit RGB, unfiltered scanlines with `iqm.png`, preserving
their byte RGB colours and discarding unused alpha. This makes the texture build
independent of Pillow, Blender's colour handling, and network availability. The
full mesh import uses these same canonical PNGs for its final skin pass. Three old
outputs differed from these external PNGs: the packed rocket muzzle glow, heavy
armour image and slug atlas; the canonical PNGs are now the source of truth.

`armor-circuit-mask.png` is an original RAVAGE mask aligned to the armour UVs:
red paints the dark Circuit V, green paints ivory lower trim. It follows the torso
in model space: V centre at `z = 20 + abs(y) * 0.5`, half-width 1.3, lower trim at
`12 < z < 15.5`. Player markings are defined directly in the player's UV regions
in `import_librequake.py`.

## Clean weapon surfaces

`weapon-materials/` contains separately authored **1024 x 1024 material maps** for
all six first-person weapons and all six world weapons. These replace the rejected
hue-threshold recolour and arbitrary wraparound trim. Original weapon diffuse noise
is not used on any surface. Broad paint, ivory inserts, graphite gaskets, rubber
grips, steel barrels, cooling channels and retaining collars are authored on
the existing UV layouts and connected physical mesh parts.

Each PNG encodes **R = material ID**, **G = finish/contact shade**, **B = emission**.
The ordinary importer combines these with the central weapon palette to produce
runtime diffuse and luma PNGs. Full model conversion finishes with this same pass.

| ID | Surface |
|---|---|
| 0 | Unused/padded background |
| 1 | Weapon identity paint |
| 2 | Warm ivory ceramic |
| 3 | Graphite mechanism/gasket |
| 4 | Machined steel |
| 5 | Rubber grip or dark bore |
| 6 | Small identity-coloured status light |
| 7 | Original animated muzzle-flash silhouette |
| 8 | Dark technical marking |
| 9 | Bright steel tip |
| 10 | Recessed identity-coloured panel line |

Current weapon maps emit only in the original muzzle-flash UVs (ID 7); IDs 6 and 8 are reserved and unused. The original source PNG is sampled solely inside the
explicit muzzle-flash UV rectangles to preserve those animation effects.
`layouts.json` records the physical part assignments, with independent view/world
maps. The maps have 12-texel filtering gutters. Soft contact shading comes from
short hemisphere rays against the actual mesh, without baked directional lights
or random wear. The finish is intentionally clean; old source grain is absent.

`tools/assets/paint_weapon_materials.py` is the artist tool for rebuilding these
maps (Pillow and numpy).
It uses each mesh's connected parts, local surface coordinates and explicit
material layouts. The rejected serial/plaque generator has been removed. No mesh,
UV, animation, gameplay or engine changes are required.

Normal builds and `--skins-only` use the committed material maps and need only
standard Python. `tests/assets.sh` regenerates and compares every diffuse/luma
output and catches stale emissive maps. Old model texture filenames are retained.

## Rocket-launcher review candidate

The rocket launcher now has its own part-specific `rocket_*` treatments, without
serials, lettering, plaques or status-light windows. Its material maps contain no
IDs 6 or 8. Red cheek shells surround a cooling spine; the exposed ivory coupling,
steel heatsink/muzzle and rubber grips follow the real parts. Narrow edge rubs
are derived only from sharp physical mesh edges, excluding triangulation diagonals.

`paint_weapon_materials.py --weapon rocketlauncher` updates just that weapon's
view/world maps and manifest entry. Other material maps are preserved. The rocket reference was approved and its finish is now used across the set.

## Approved finish rollout

After the rocket-launcher finish was approved, it was carried across the shotgun,
machine gun, grenade launcher, lightning gun and railgun, including world models.
Each has explicit `circuit_*` physical-part layouts: pump, feed drum, chamber,
insulators/electrodes and rail/power housing respectively. Shared shell, coupling,
grip and heatsink treatments reuse the approved reference. All twelve maps omit
ink/status-light IDs. The approved rocket remains byte-identical.
