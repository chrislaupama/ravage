# content/

Original maps, models, materials, effects and audio.

| Path | What it is |
|---|---|
| `maps/` | TrenchBroom map sources (Valve 220). Compiled by `tools/build-game-data.sh`. |
| `textures/ravage.wad` | Graybox textures, generated by `tools/textures/make_textures.py` |
| `gfx/palette.lmp` | The RAVAGE palette, generated by the same script |

See [docs/mapping.md](../docs/mapping.md) for the map workflow.

Everything here must be original or properly licensed for RAVAGE. Do not add any id Software Quake assets (for example `pak0.pak`, `pak1.pak` or anything from `id1/`). See [docs/licensing.md](../docs/licensing.md).
