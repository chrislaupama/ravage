# content/

Original maps, models, materials, effects and audio.

| Path | What it is |
|---|---|
| `maps/` | TrenchBroom map sources (Valve 220). Compiled by `tools/build-game-data.sh`. |
| `textures/ravage.wad` | Graybox textures, generated by `tools/textures/make_textures.py` |
| `gfx/palette.lmp` | The RAVAGE palette, generated by the same script |
| `models/` | Models. The player (IQM) and the six weapons (animated MD3 first-person models and IQM pickups) come from LibreQuake (BSD-3, see `models/LICENSE.librequake`), with recoloured skins, via `tools/assets/import_librequake.py`. Health, armor, ammo and projectiles (IQM) and their shared skin are placeholders generated by `tools/assets/make_models.py`. |
| `sound/` | Placeholder sounds (WAV): weapons, explosions, pickups, pain, death, teleporters and jump pads. Generated by `tools/assets/make_sounds.py`. |

See [docs/mapping.md](../docs/mapping.md) for the map workflow.

The generated files are committed so the game builds without Python. Don't edit them by hand: change the script and run it again. `tests/assets.sh` (run by `ctest`) fails when they are out of date. The LibreQuake import needs Blender's Python module and a LibreQuake checkout, so the test only checks that its files are present.

Everything here must be original or properly licensed for RAVAGE, and third-party content keeps its license and credits next to it. Do not add any id Software Quake assets (for example `pak0.pak`, `pak1.pak` or anything from `id1/`). See [docs/licensing.md](../docs/licensing.md).
